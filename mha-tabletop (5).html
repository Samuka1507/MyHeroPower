    🏆 Sistema de Ranking

    Ranking pessoal e de agência sobem com missões, combates e reputação.

    Ranking Pessoal (Heróis)

    • Rank C: Estudante / iniciante
    • Rank B: Herói provisório / sidekick forte
    • Rank A: Herói profissional consolidado
    • Rank S: Top 10 / símbolo nacional

    Como subir

    • Missão concluída: +10–40 pts
    • Derrotar vilão Rank igual ou maior: +15–50 pts
    • Salvar civis / ação heroica: +5–20 pts
    • Falha pública / dano colateral: −10 pts

    C→B: 50 pts · B→A: 120 pts · A→S: 250 pts

    📖 Regras Claras

    Combate

    1. Iniciativa: d20 + Agilidade
    2. No turno: mover + 1 ação
    3. Ataque: d20 + Técnica (ou Força) vs CA do alvo
    4. Acertou (≥ CA) → rola dano e anota
    5. Crítico (20): dano ×2 · Falha (1): errou + complicação

    Danos

    • Básico: 1d6 + Poder/2
    • Especial (3 energia): 2d6 + Poder
    • Quirk (custo): 1d8 + Controle/2
    • Plus Ultra (5): vantagem + 2d6 + Poder

    XP / Ranking / Quirk / Agência

    • XP personagem: Nível × 100 para subir
    • QXP (Quirk): Nível do Quirk × 50 para evoluir
    • Rank pessoal: pontos de ranking (missão/combate)
    • Agência: Reputação + AXP para subir rank D→S
