# MyHeroPower — MHA Tabletop RPG

Sistema de RPG de mesa inspirado em **My Hero Academia**, com suporte completo a Quirks simples, moderadas e complexas.

## Arquivos

| Arquivo       | Descrição                          |
|---------------|------------------------------------|
| `index.html`  | Estrutura principal da aplicação   |
| `style.css`   | Todos os estilos                   |
| `app.js`      | Toda a lógica JavaScript           |
| `README.md`   | Este arquivo                       |

## Como usar

1. Extraia o ZIP
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, etc.)
3. Não precisa de internet nem de servidor

## Principais recursos

- Ficha completa de personagem (Herói, Vilão, Vigilante...)
- **Sistema de Quirks flexível**:
  - Simples → efeito direto
  - Moderada → com escala ou condições
  - Complexa → narrativa, emoções, medo, fatores externos (ex: **Medo Materializado**)
- Combate, iniciativa, inimigos, mapa tático
- Agência, missões, ranking, dados e ferramentas de Mestre
- Salvamento local (localStorage) + exportação JSON
- Aba **📖 Regras** com guia completo de criação de personagem, NPCs, dados e Quirks

## Exemplo de Quirk Complexa incluída

**Medo Materializado** — O usuário materializa os medos das pessoas ao redor. O poder escala com a intensidade do medo (controlada pelo Mestre) e causa feedback emocional no usuário.
